### Candidate findings checked and dismissed (with evidence)

- **Snapshot-wins-on-id-collision claim** (`activityStore.ts` restore comment): verified — `sanitizeActivities` (`activityStore.ts:71-86`) filters → de-dupes keep-first → sorts → caps, in that order, so listing the snapshot first does make it win. The new store test asserts it.
- **StrictMode / timer ownership (R3):** effect at `ActivityFeed.tsx:145-168` creates and clears its own id per invocation; deps `[isWindowOpen, undoWindowKey]`; `undoWindowKey++` on every clear restarts the window; unmount cleanup clears it. Test "no timer callback and no console error after unmount" asserts `clearTimeout` was called with the exact id. Sound.
- **Focus effect deps `[isWindowOpen, hasStoredEntries]`:** Clear→Undo (isWindowOpen flips), Undo→Clear (both flip), second Clear (hasStoredEntries flips true→false because Clear only renders when true). All three transitions change a dep in the same commit that mounts the target. Sound on the happy path (F3 covers the unhappy path).
- **Expiry focus read before state update** (`:152`): correct ordering; heading has `tabIndex={-1}` and `ref`; test asserts heading has focus and body does not.
- **R8 in-memory consistency:** subscriber `setActivities(getVisibleActivities())` is queued first by the synchronous `notifySubscribers()`; handler's `setActivities([])`/`setActivities(restored.slice(0,20))` is queued last in the same discrete-event batch and wins. Component test with `setItem` throwing asserts the list empties. Accepted "persistence degraded" behaviour (old entries resurface on the next `addActivity`) is recorded in plan.md "What could this break?".
- **No self-logging (R5):** neither `clearActivities` nor `restoreActivities` calls `addActivity`; test asserts counts.
- **Copy/query collisions:** new strings `Clear activity`, `Undo`, `Activity cleared.`, `Activity restored.` ≠ `settings` / `just now` / `On` / `Off`; the empty state renders no `ul`/`li`/`role=list` (header/notice are `div`, status is `p`); existing 37 tests pass unmodified.
- **`console` output:** `grep -rn "console\." src/activity/activityStore.ts src/activity/ActivityFeed.tsx` → empty.
- **`.activity-feed__title:focus { outline: none; }`:** heading is `tabIndex=-1` (not in tab order, only receives programmatic focus on expiry); designed and approved (TEAM-4176). Not filed.
